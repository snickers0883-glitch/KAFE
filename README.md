# Вкусный кофе — сайт кофейни (Ташкентская, 138)

HTML + Tailwind (CDN) + Vanilla JS. База данных и API — Google Таблица + Google Apps Script.

## Структура

```
vkusny-kofe/
├── index.html            # публичный сайт
├── admin.html            # админ-панель (вход, меню, тексты сайта, брони)
├── js/
│   ├── config.js         # ← ВСЕ настройки: URL Apps Script, API_KEY, SYSTEM_PROMPT
│   ├── api.js            # запросы к Apps Script + демо-данные
│   ├── app.js            # логика сайта (меню, бронь, копирование адреса)
│   ├── chat.js           # AI-бариста
│   └── admin.js          # логика админки
└── apps-script/
    └── Code.gs           # бэкенд (вставляется в Google Apps Script)
```

Без настройки сайт работает в **демо-режиме** (примерное меню, брони не сохраняются, вход в админку принимает любой логин/пароль). Достаточно открыть `index.html`.

## Развёртывание бэкенда (Google Apps Script)

1. Создайте новую **Google Таблицу** (sheets.new), назовите «Вкусный кофе — база».
2. Меню **Расширения → Apps Script**. Удалите содержимое `Code.gs` и вставьте код из `apps-script/Code.gs`. Сохраните (Ctrl+S).
3. В выпадающем списке функций выберите **`setup`** и нажмите **Выполнить**. Разрешите доступ (Google покажет «приложение не проверено» → *Дополнительно → Перейти*). Появятся листы: `Меню`, `Настройки`, `Брони`, `Админы`.
4. Логин по умолчанию: **admin** / **admin123**. Сразу смените в админке (вкладка «Аккаунт»).
5. **Развернуть → Новое развёртывание → тип «Веб-приложение»**:
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
   - Нажмите «Развернуть» и скопируйте **URL веб-приложения** (оканчивается на `/exec`).
6. Откройте `js/config.js` и вставьте URL в `APPS_SCRIPT_URL`.
7. Проверка: откройте `URL?action=public` в браузере — должен вернуться JSON с меню.

> ⚠️ После **любого** изменения `Code.gs` нужно: **Развернуть → Управление развёртываниями → ✏️ → Версия: «Новая версия» → Развернуть**. URL при этом не меняется.

## AI-бариста

Настройки в `js/config.js`: `AI_PROVIDER` (`gemini`/`openai`), `AI_MODEL`, `API_KEY`, `SYSTEM_PROMPT`.

Два режима (`CHAT_MODE`):

- **`direct`** — запросы идут из браузера. Просто, но **ключ виден любому, кто откроет код страницы**. Подходит для теста; обязательно ограничьте ключ (в Google AI Studio / Cloud Console — по HTTP-referrer домена сайта и поставьте лимит расходов).
- **`proxy`** (рекомендуется) — запросы идут через Apps Script, ключ лежит в *Параметры проекта → Свойства скрипта*: `AI_API_KEY`, `AI_PROVIDER`, `AI_MODEL`. В `config.js` поставьте `CHAT_MODE: "proxy"` и оставьте `API_KEY` пустым. В прокси встроен лимит 300 запросов/час.

Бариста автоматически получает актуальное меню из таблицы, поэтому не выдумывает позиции.

## Как пользоваться админкой

Откройте `admin.html` (ссылка «Вход для персонала» в подвале сайта).

- **Меню** — добавить / изменить / удалить позицию, скрыть с сайта (галочка «Показывать»), порядок, ссылка на картинку.
- **Сайт** — заголовки, описания, адрес, телефон, часы, карта, картинки.
- **Брони** — все заявки, смена статуса (новая / подтверждена / отменена), удаление.
- **Аккаунт** — смена пароля. Ещё админ: в редакторе Apps Script запустите `addAdmin("логин","пароль")`.

Изменения сразу пишутся в таблицу; сайт подтягивает их при следующей загрузке страницы.
Таблицу можно править и руками — это тот же источник данных.

## Публикация сайта

Статические файлы — подойдёт Netlify, Vercel, GitHub Pages, Cloudflare Pages (перетащить папку). Локально: `python3 -m http.server 8080`.

## Безопасность — коротко

- Пароли хранятся как SHA-256 + соль; сессия — токен в кэше на 6 часов; 5 неверных попыток блокируют вход на 5 минут.
- Все данные из таблицы выводятся с экранированием (защита от XSS), в ячейки броней нельзя внедрить формулы.
- Форма брони: валидация на клиенте и сервере, скрытое поле-ловушка для ботов, лимит 1 заявка / 30 сек на телефон.
- Apps Script не умеет отдавать заголовки CORS на preflight, поэтому POST отправляется как `text/plain` — так задумано.
- Картинки: подставлены примеры с Unsplash. Ссылки на изображения Pinterest часто защищены от встраивания, поэтому лучше загрузить свои фото на любой хостинг (или Imgur) и вставить прямые ссылки в админке. Цены в примерах указаны в ₸ — поменяйте валюту в `app.js` (функция `money`), если нужна другая.
